# Release Checklist

## Pre-release
- [ ] Update `docs/CHANGELOG.md` with release notes.
- [ ] Verify Java compatibility in `README.md`.
- [ ] Run unit tests and ensure green build.
- [ ] Confirm `settings.xml` uses environment variables for credentials.

## Release
- [ ] Tag the release version in git.
- [ ] Publish artifacts to Maven Central.

## Post-release
- [ ] Update documentation with released version.
- [ ] Create GitHub release notes.
